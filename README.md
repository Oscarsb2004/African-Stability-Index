# athena-core

The shared backend of **Athena**: engines, checks, connectors and view shells used by more than one project.

> **Empty on purpose.** Nothing enters this repository until a second project uses it unchanged (Athena Standard rule `std:MOD-01`, decision A17). The first code here will arrive in an **extraction pull request** with two consuming projects' checks passing, planned in section S06.

- **Agent instructions:** `AGENTS.md`
