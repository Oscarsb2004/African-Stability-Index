# African-Instability-Index
A project aiming to create instability scores in 7 different domains/pillars for every country in Africa. Primarily World Bank datasets, paired with historical/qualitative information about the stressors affecting each country.

For file structure, Files __init__.py, countries.py, indicator.py, nation.py, pillar.py are in a folder named models.
Outside of the models folder is config.py
