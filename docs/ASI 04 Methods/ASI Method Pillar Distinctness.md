# ASI Method Pillar Distinctness

> [!abstract] Goal
> Show, with numbers, that the pillars measure different things, and stop any layout that blurs them.

## Why it exists

If pillars cannot be told apart, eight scores tell the reader no more than one.

## Precise objectives

1. Report pillar correlations with n and interval, corrected for attenuation.
2. Report HTMT for every pair (target below .85), and Fornell–Larcker.
3. Factor analysis at the pillar level with parallel analysis, repeated with GDP held constant.
4. Rerun on every edition's panel, and report the result whatever it shows.

**Evidence (edition 1, 2023).** 12 of 21 pillar pairs reach |.90| once corrected for reliability. KMO .784; eigenvalues 4.44, 1.24, 0.59; parallel analysis keeps one factor. With GDP held constant: 3.13, 1.73, 0.95, and governance-and-security separates from human development. The layout test is in [ASI Pillars](<ASI Pillars.md>).

## Inputs and outputs

- **In:** pillar scores
- **Out:** distinctness diagnostics in the advisory layer

## Where it stands

Built as a report (the advisory layer). Rerun at edition 2, step 6 (2024, n = 52): seven pairs pass |.90| once corrected, every one involving COH or ENV, which are formative, so the reflective correction does not fit them; KMO .747; eigenvalues 3.93, 1.19, 0.80, and 3.25, 1.38, 0.92 with GDP held constant; parallel analysis keeps one factor.
