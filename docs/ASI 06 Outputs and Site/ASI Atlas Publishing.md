# ASI Atlas Publishing

> [!abstract] Goal
> Publish the atlas as a static site once it reaches parity with the Dash site, with the imagery key kept out of git.

## Why it exists

Only the owner publishes (AGENTS). The live site is the legacy edition until then (P44).

## Precise objectives

1. A parity checklist against the Dash site, ticked before switching (P59).
2. A GitHub Pages build with `VITE_BASE`, the Esri key as an Actions secret, restricted by referrer.
3. The owner decides where it is served (the public ASI repository or another).

## Inputs and outputs

- **In:** the built site
- **Out:** the public atlas

Planned.
